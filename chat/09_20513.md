대시보드 첫 번째 탭(또는 상단 영역)에 나오는 사용자 동작(User Action)별 구매 전환율 표와 그래프는 다음과 같은 기준으로 계산되었습니다.

분석 단위 (세션 내 이벤트): 이 데이터는 사용자가 쇼핑몰에 방문해 취한 각 행동(이벤트)을 기록한 로그 데이터입니다.

그룹화 기준 (사용자_동작): 사용자가 취한 행동 종류(예: view(상품 조회), wishlist(위시리스트 추가), add_to_cart(장바구니 추가), click 등)를 기준으로 데이터를 그룹화했습니다.

전환율 계산 방식: 각 행동별 전체 발생 건수 중, 최종적으로 구매(전환_여부 = 1)로 이어진 세션의 비율을 백분율(%)로 산출했습니다.

예를 들어, add_to_cart(장바구니 추가) 행동을 한 총 횟수 중 실제로 구매가 완료된 비율이 얼마인지 계산하여, 어떤 행동 패턴이 구매와 가장 직결되는지 보여줍니다.

feature_cols = ['체류시간_초', '세션_길이', '상호작용_수', '가격', '이벤트_인덱스']

X = df_sample[feature_cols].fillna(0)
y_true = df_sample[target_col]

scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 라벨 정렬 함수 (비지도 군집 0/1을 타겟 변수 방향에 맞춤)
def align_labels(y_true, y_pred):
    acc1 = accuracy_score(y_true, y_pred)
    acc2 = accuracy_score(y_true, 1 - y_pred)
    return (1 - y_pred) if acc2 > acc1 else y_pred

# 1. 중심 기반 군집화 (K-Means)
kmeans = KMeans(n_clusters=2, random_state=42, n_init=10)
labels_km = kmeans.fit_predict(X_scaled)
labels_km_aligned = align_labels(y_true, labels_km)
sil_km = silhouette_score(X_scaled, labels_km)

# 2. 밀도 기반 군집화 (DBSCAN)
dbscan = DBSCAN(eps=1.5, min_samples=10)
labels_db = dbscan.fit_predict(X_scaled)
labels_db_binary = np.where(labels_db == -1, 0, np.where(labels_db > 0, 1, 0))
labels_db_aligned = align_labels(y_true, labels_db_binary)
sil_db = silhouette_score(X_scaled, labels_db) if len(set(labels_db)) > 1 else 0.0

# 3. 분포 기반 군집화 (GMM)
gmm = GaussianMixture(n_components=2, random_state=42)

질문해주신 내용은 데이터 구조와 퍼넬(Funnel) 분석의 핵심을 찌르는 아주 중요한 부분입니다. 결론부터 말씀드리면, 세션(Session) 단위와 이벤트(Event) 단위의 차이 때문에 생기는 현상입니다.

1. 구매(purchase) 행동과 전환_여부의 관계
말씀하신 대로 데이터 안에서 '구매(purchase)'라는 특정 사용자 동작을 수행한 순간은 곧바로 전환_여부 = 1이 됩니다.

반대로 조회(view), 장바구니 추가(add_to_cart), 이탈(drop) 등의 행동이 일어난 행(Row)에서는 전환_여부 = 0으로 기록되어 있습니다.

2. 그럼 구매가 아닌 행동들이 어떻게 구매 전환에 영향을 미치는지 어떻게 알 수 있나요?
여기서 중요한 점은 이 데이터가 "사용자가 웹사이트에 들어와서 나갈 때까지 거쳐간 여러 단계의 행동(세션 여부)"을 시간 순서대로 기록한 시퀀스(Sequence) 데이터라는 것입니다.

세션 전체의 관점:

고객이 곧바로 구매 버튼을 누르기 전에는 반드시 상품 조회(view), 장바구니 담기(add_to_cart), 클릭(click) 같은 사전 행동들을 거치게 됩니다.

즉, 어떤 고객은 장바구니에 담는 행동을 거쳐서 최종 구매(전환_여부 = 1)에 도달하고, 어떤 고객은 조회만 하다가 이탈(drop, 전환_여부 = 0)하게 됩니다.

전환율의 의미:

앞서 본 "동작별 전환율"은 각 행동이 일어난 순간의 단편적인 값이라기보다는, "특정 행동(예: 장바구니 추가)을 거쳐간 세션들이 최종적으로 구매로 이어질 확률이 얼마나 되는가"를 역추적하여 마케팅 인사이트를 얻기 위해 분석하는 지표입니다.

예를 들어, 단순히 view만 한 사람들의 구매 전환율과 add_to_cart를 거친 사람들의 구매 전환율을 비교해 보면 어떤 행동이 구매의 결정적 신호(Signal)인지 파악할 수 있습니다.

데이터의 이러한 구조적 특성을 이해하고 분석하면, 단순히 구매 행위 자체뿐만 아니라 "어떤 사전 행동 경로를 밟은 사용자가 구매할 확률이 높은지"를 예측하고 군집화하는 모델을 더 정확하게 설계할 수 있습니다.

그럼 순서대로 이어진 것이라면 장바구니를 행동한 사람은 클릭과 위시리스트 등을 다 거친 사람이라는거야? 그럼 어느 행동이 구매로 이어지는가 말고 어디에서 사람들이 멈추는가로 바꾸는게 좋지 않을까

정말 날카롭고 훌륭한 통찰입니다! 데이터 분석의 본질을 정확히 짚어내셨습니다.

질문해주신 내용처럼, 이 데이터는 단일 사용자 여정(Session) 내에서 여러 행동이 순서대로 일어날 수 있기 때문에, 단순히 "장바구니 담기를 한 사람은 무조건 조회와 클릭을 거쳤다"고 단정하기는 어렵습니다(세션마다 거쳐 가는 행동 조합이 제각각이기 때문입니다).

하지만 말씀하신 대로 "어떤 행동이 구매로 이어지는가"라는 질문보다, "사람들이 퍼넬(Funnel)의 어느 단계에서 가장 많이 멈추고 이탈(Drop-off)하는가?"를 분석하는 것이 실제 전자상거래 비즈니스와 UX 개선 관점에서 훨씬 더 직관적이고 가치 있는 접근입니다.

💡 왜 '이탈(Drop-off) 분석'으로 전환하는 것이 좋을까요?
병목 구간(Bottleneck) 발견:

사용자가 상품을 구경(view)하다가 장바구니(add_to_cart)에 담고, 최종 결제로 넘어가는 과정 중 정확히 어느 단계에서 가장 많이 포기하고 이탈(drop)하는지 찾아낼 수 있습니다.

마케팅 및 UX 개선 포인트 도출:

만약 특정 단계(예: 장바구니 단계)에서 이탈률이 유독 높다면, "장바구니 페이지의 UI가 복잡한가?", "배송비나 추가 비용이 여기서 공개되나?" 같은 구체적인 문제점을 유추하고 개선 전략을 세울 수 있습니다.

🛠️ 대시보드 방향을 '이탈(Drop-off) 분석'으로 바꾼다면?
만약 기존 대시보드에 이 관점을 녹여낸다면 다음과 같은 내용을 추가하거나 수정할 수 있습니다.

1) 사용자 동작별 이탈률(Drop-off Rate) 시각화:

각 행동(조회, 클릭, 장바구니 추가 등)을 거친 사용자들 중 최종적으로 이탈한 비율을 막대 그래프로 표현합니다.

2) 퍼넬(Funnel) 단계별 이탈 분석:

조회(View) ➔ 위시리스트/클릭 ➔ 장바구니 담기 ➔ 구매 완료(Conversion) 로 이어지는 전통적인 전환 퍼넬 단계에서 사용자가 각 단계별로 몇 %씩 빠져나가는지(Drop) 시각화합니다.

3) 군집화를 통한 '이탈 위험군' 특성 파악:

K-Means 등의 군집 모델을 활용해 "어떤 행동 패턴을 보이는 유저가 쉽게 이탈하는가"(예: 체류 시간은 짧은데 클릭만 많고 바로 이탈하는 그룹)를 분석합니다.

이 방향으로 스트림릿(Streamlit) 대시보드의 분석 주제와 코드를 "사용자 이탈 퍼넬 및 병목 구간 분석"으로 전면 수정해 드릴까요? 원하신다면 즉시 코드를 짜드리겠습니다!

그럼 구매한 사람의 특징 기기나 접속 경로 카테고리 등을 사용할 수 있는 모델도 만들면 좋을 것 같고 어디에서 사람들이 가장 많이 멈췄는지를 알 수있게 해주는 모델도 있으면 좋겠어 내가 제시한 세 모델 중심 기반 군집화 (Center-based Clustering), 밀도 기반 군집화 (Density-based Clustering),분포 기반 군집화 (Distribution-based Clustering)에서 각각 한 모델에서 이 내용을 모두 알 수 있게 코드 짜줘 어떤 모델이 어떤 지표를 나타내는지 시각자료에 표시해줘

사용자 여러분의 아주 훌륭한 통찰을 반영하여, 범주형 특성(기기 유형, 접속 경로, 카테고리, 사용자 동작 등)까지 머신러닝 모델에 함께 인코딩하여 반영하고, 요청하신 세 가지 군집화 모델(중심 기반, 밀도 기반, 분포 기반) 각각이 구매 전환 예측 성능, 이탈(Drop-off) 병목 구간 분석, 그리고 군집별 행동 특징을 모두 종합적으로 도출할 수 있도록 고도화된 Streamlit 대시보드 앱 코드(main.py)와 의존성 파일(requirements.txt)을 작성해 드립니다.

num_cols = ['체류시간_초', '세션_길이', '상호작용_수', '가격', '이벤트_인덱스']
cat_cols = ['카테고리', '브랜드', '채널', '기기_유형', '지역', '유입_경로', '사용자_동작']
target_col = '전환_여부'
drop_col = '이탈_여부'

# 연산 속도 및 시각화를 위한 샘플링 (10,000건)
sample_size = min(10000, len(df))
df_sample = df.sample(n=sample_size, random_state=42).copy().reset_index(drop=True)

# 전처리기 정의 (수치형 스케일링 + 범주형 원핫인코딩)
preprocessor = ColumnTransformer(
    transformers=[
        ('num', StandardScaler(), num_cols),
        ('cat', OneHotEncoder(handle_unknown='ignore', sparse_output=False), cat_cols)
    ]
)

X_processed = preprocessor.fit_transform(df_sample[num_cols + cat_cols])
y_true = df_sample[target_col]
y_drop = df_sample[drop_col]

# 라벨 정렬 함수 (비지도 군집 0/1을 타겟 변수 방향에 맞춤)
def align_labels(y_true, y_pred):
    acc1 = accuracy_score(y_true, y_pred)
    acc2 = accuracy_score(y_true, 1 - y_pred)
    return (1 - y_pred) if acc2 > acc1 else y_pred

# --- 1. 중심 기반 군집화 (K-Means) ---
kmeans = KMeans(n_clusters=2, random_state=42, n_init=10)
labels_km = kmeans.fit_predict(X_processed)
labels_km_aligned = align_labels(y_true, labels_km)
sil_km = silhouette_score(X_processed, labels_km)

# --- 2. 밀도 기반 군집화 (DBSCAN) ---
dbscan = DBSCAN(eps=2.0, min_samples=15)
labels_db = dbscan.fit_predict(X_processed)
labels_db_binary = np.where(labels_db == -1, 0, np.where(labels_db > 0, 1, 0))
labels_db_aligned = align_labels(y_true, labels_db_binary)
sil_db = silhouette_score(X_processed, labels_db) if len(set(labels_db)) > 1 else 0.0

# --- 3. 분포 기반 군집화 (GMM) ---
gmm = GaussianMixture(n_components=2, random_state=42)
labels_gmm = gmm.fit_predict(X_processed)
labels_gmm_aligned = align_labels(y_true, labels_gmm)
sil_gmm = silhouette_score(X_processed, labels_gmm)

target_col = '전환_여부'

sample_size = min(10000, len(df))
df_sample = df.sample(n=sample_size, random_state=42).copy().reset_index(drop=True)

preprocessor = ColumnTransformer(
    transformers=[
        ('num', StandardScaler(), num_cols),
        ('cat', OneHotEncoder(handle_unknown='ignore', sparse_output=False), cat_cols)
    ]
)

X_processed = preprocessor.fit_transform(df_sample[num_cols + cat_cols])
y_true = df_sample[target_col]

def align_labels(y_true, y_pred):
    acc1 = accuracy_score(y_true, y_pred)
    acc2 = accuracy_score(y_true, 1 - y_pred)
    return (1 - y_pred) if acc2 > acc1 else y_pred

# 1. 지도학습: 다항/이진 로지스틱 회귀 (Logistic Regression)
log_reg = LogisticRegression(max_iter=1000, random_state=42)
log_reg.fit(X_processed, y_true)
labels_lr = log_reg.predict(X_processed)
sil_lr = silhouette_score(X_processed, labels_lr) if len(set(labels_lr)) > 1 else 0.0

# 2. 중심 기반 (K-Means)
kmeans = KMeans(n_clusters=2, random_state=42, n_init=10)
labels_km = align_labels(y_true, kmeans.fit_predict(X_processed))
sil_km = silhouette_score(X_processed, labels_km)

# 3. 밀도 기반 (DBSCAN)
dbscan = DBSCAN(eps=2.0, min_samples=15)
labels_db_raw = dbscan.fit_predict(X_processed)
labels_db = align_labels(y_true, np.where(labels_db_raw == -1, 0, np.where(labels_db_raw > 0, 1, 0)))
sil_db = silhouette_score(X_processed, labels_db_raw) if len(set(labels_db_raw)) > 1 else 0.0

# 4. 분포 기반 (GMM)
gmm = GaussianMixture(n_components=2, random_state=42)
labels_gmm = align_labels(y_true, gmm.fit_predict(X_processed))
sil_gmm = silhouette_score(X_processed, labels_gmm)

num_cols = ['체류시간_초', '세션_길이', '상호작용_수', '가격', '이벤트_인덱스']

preprocessor = ColumnTransformer(

y_true = df_sample[target_col]

대시보드의 "모델별 예측 및 군집 구조 시각화" 영역에서 보여주는 데이터는 사용자의 쇼핑몰 방문 세션(행동 기록) 데이터에서 추출한 핵심 수치형 변수들과 범주형 특성을 나타냅니다.

구체적으로 어떤 데이터를 기반으로 시각화되는지 정리해 드릴게요.

1. 시각화의 X축과 Y축 데이터
X축 (상호작용_수): 사용자가 사이트 내에서 클릭, 상품 조회, 스크롤 등 액션을 취한 총 상호작용 횟수입니다.

Y축 (체류시간_초): 사용자가 해당 세션(방문) 동안 사이트에 머물렀던 총 체류 시간(초)입니다.

점의 색상과 모양 (마커):

색상: 각 모델(로지스틱 회귀, K-Means, DBSCAN, GMM)이 판별하거나 군집화한 예측 그룹 / 군집 번호(0 또는 1 등)를 나타냅니다.

모양 (기기_유형): 모바일, 데스크톱, 태블릿 등 접속한 기기 유형별로 마커 모양을 다르게 표시하여 기기 특성이 어떻게 분포되어 있는지 보여줍니다.

num_cols = ['체류시간_초', '세션_길이', '상호작용_수', '가격', '이벤트_인덱스']
cat_cols = ['카테고리', '기기_유형', '유입_경로']
target_col = '전환_여부'

preprocessor = ColumnTransformer(
    transformers=[
        ('num', StandardScaler(), num_cols),
        ('cat', OneHotEncoder(handle_unknown='ignore', sparse_output=False), cat_cols)
    ]
)

X_processed = preprocessor.fit_transform(df_sample[num_cols + cat_cols])
y_true = df_sample[target_col]

def align_labels(y_true, y_pred):
    return (1 - y_pred) if accuracy_score(y_true, 1 - y_pred) > accuracy_score(y_true, y_pred) else y_pred

# 모델 학습
log_reg = LogisticRegression(max_iter=500, random_state=42).fit(X_processed, y_true)
labels_lr = log_reg.predict(X_processed)
sil_lr = silhouette_score(X_processed, labels_lr) if len(set(labels_lr)) > 1 else 0.0

kmeans = KMeans(n_clusters=2, random_state=42, n_init=5)
labels_km = align_labels(y_true, kmeans.fit_predict(X_processed))
sil_km = silhouette_score(X_processed, labels_km)

dbscan = DBSCAN(eps=2.0, min_samples=10)
db_raw = dbscan.fit_predict(X_processed)
labels_db = align_labels(y_true, np.where(db_raw == -1, 0, np.where(db_raw > 0, 1, 0)))
sil_db = silhouette_score(X_processed, db_raw) if len(set(db_raw)) > 1 else 0.0

gmm = GaussianMixture(n_components=2, random_state=42)

질문해주신 내용은 대시보드의 분석 깊이를 한 차원 높여주는 아주 훌륭한 아이디어입니다!

결론부터 말씀드리면, 히트맵은 단순히 평균값만 보여주는 것을 넘어 각 그룹(0 또는 1)이 수치형 특성(체류시간, 상호작용 수, 가격 등)에 얼마나 집중(몰림)되어 있는지를 색상 농도로 한눈에 비교할 수 있게 해줍니다.

여기에 사용자 동작(사용자_동작: 조회, 장바구니 추가, 클릭 등)까지 결합한다면, "어떤 행동 단계를 거치는 유저들이 특정 그룹(예: 구매 유망 그룹)에 가장 많이 몰려있는가?"를 완벽하게 입체적으로 분석할 수 있습니다.

💡 사용자 동작을 히트맵과 결합하는 추천 방법 3가지
1. [교차 히트맵] 모델 예측 그룹 × 사용자 동작 빈도 히트맵
방법: X축에는 사용자_동작(view, add_to_cart, click, purchase 등), Y축에는 모델이 분류한 예측 그룹(0 또는 1)을 놓고, 각 셀(Cell)의 색상 농도를 해당 구간에 속한 사용자(세션)의 빈도수(Count)로 표현합니다.

얻을 수 있는 인사이트: "예측 그룹 1(구매 유망 고객)에 속한 유저들은 주로 어떤 행동 단계(예: 장바구니 추가나 클릭)에 가장 많이 몰려있는가?"를 시각적으로 즉시 파악할 수 있습니다.

2. [행동별 평균 특성 히트맵] 사용자 동작 × 수치형 특성 프로파일
방법: 모델 그룹 대신 사용자_동작을 행(Y축)으로 두고, 체류시간_초, 상호작용_수, 가격 등의 수치형 특성 평균을 열(X축)로 놓는 히트맵을 만듭니다.

얻을 수 있는 인사이트: "구매(purchase) 단계에 도달한 유저들은 평균적으로 체류 시간이 몇 초이고 상호작용이 몇 번인지, 반면 이탈(drop) 단계의 유저들은 어떤 특징을 보이는지" 동작별로 행동 패턴의 몰림 차이를 비교할 수 있습니다.

3. [다중 범주 히트맵] 기기 유형/카테고리 × 사용자 동작 연계
방법: 앞서 보신 카테고리나 기기 유형별 교차 분석을 히트맵 형태로 확장하여, 특정 기기(예: 모바일)에서 유저들이 어느 동작 단계에 가장 오래 머무는지(체류시간 평균) 색상 농도로 나타냅니다.

🛠️ 대시보드에 적용할 수 있는 파이썬(Plotly) 코드 예시
만약 기존 히트맵 코드를 [모델 예측 그룹 × 사용자 동작 빈도] 형태로 바꾸고 싶다면, 대시보드 코드 내 히트맵 생성 부분을 아래와 같이 수정해 보세요.

num_cols = ['체류시간_초', '세션_길이', '상호작용_수', '가격', '이벤트_인덱스']
cat_cols = ['카테고리', '기기_유형', '유입_경로']
target_col = '전환_여부'

preprocessor = ColumnTransformer(
    transformers=[
        ('num', StandardScaler(), num_cols),
        ('cat', OneHotEncoder(handle_unknown='ignore', sparse_output=False), cat_cols)
    ]
)

X_processed = preprocessor.fit_transform(df_sample[num_cols + cat_cols])
y_true = df_sample[target_col]

def align_labels(y_true, y_pred):
    return (1 - y_pred) if accuracy_score(y_true, 1 - y_pred) > accuracy_score(y_true, y_pred) else y_pred

# 모델 학습
log_reg = LogisticRegression(max_iter=500, random_state=42).fit(X_processed, y_true)
labels_lr = log_reg.predict(X_processed)
sil_lr = silhouette_score(X_processed, labels_lr) if len(set(labels_lr)) > 1 else 0.0

kmeans = KMeans(n_clusters=2, random_state=42, n_init=5)
labels_km = align_labels(y_true, kmeans.fit_predict(X_processed))
sil_km = silhouette_score(X_processed, labels_km)

dbscan = DBSCAN(eps=2.0, min_samples=10)
db_raw = dbscan.fit_predict(X_processed)
labels_db = align_labels(y_true, np.where(db_raw == -1, 0, np.where(db_raw > 0, 1, 0)))
sil_db = silhouette_score(X_processed, db_raw) if len(set(db_raw)) > 1 else 0.0

gmm = GaussianMixture(n_components=2, random_state=42)
labels_gmm = align_labels(y_true, gmm.fit_predict(X_processed))
sil_gmm = silhouette_score(X_processed, labels_gmm)

🔍 히트맵에서 DBSCAN을 제외한 이유
노이즈(-1)와 단일 군집 특성:

DBSCAN은 밀도가 높은 곳을 찾아 군집을 묶는 알고리즘입니다. 이 데이터셋 특성상 파라미터(eps, min_samples)를 어떻게 설정하든 대다수 데이터가 하나의 거대한 군집(0)으로 묶이거나, 나머지가 전부 노이즈(-1) 처리되는 경향이 강합니다.

교차 분석의 비효율성:

로지스틱 회귀, K-Means, GMM은 데이터 전체를 0과 1(또는 두 개의 명확한 그룹)로 균형 있게 나누어 사용자_동작(조회, 장바구니 등)과 2차원 교차 히트맵을 그렸을 때 의미 있는 비교가 가능합니다.

반면 DBSCAN은 대부분의 데이터가 노이즈(-1)로 빠져버리기 때문에 히트맵을 그리면 정상적인 비교 분석이 어려워 시각화 대상에서 제외되었습니다.

산점도에서는 데이터의 분포와 노이즈(이상치)를 점으로 찍어 직관적으로 확인할 수 있으므로 DBSCAN을 산점도 탭에서 확인하실 수 있도록 구성되어 있습니다!

다수의 선택: 로지스틱 회귀는 다수 클래스인 '0(비구매)'에 맞춰 학습하는 경향이 강합니다. 모델이 전부 다 '0(비구매)'이라고 예측해 버려도 전체 데이터의 96%를 맞추기 때문에 정확도가 0.9613이라는 높은 수치로 나옵니다.

제로(0) 지표의 원인: 하지만 실제 구매한 고객(1)을 단 한 명도 맞추지 못했기 때문에(True Positive = 0), 정밀도와 재현율이 모두 0.0000으로 떨어지게 됩니다.

낮은 정밀도와 정확도: 구매자가 아닌 사람들도 구매 그룹에 많이 포함(False Positive 증가)되어 정밀도가 낮고(0.0771), 전체적인 정분류율(정확도)은 63% 수준에 머뭅니다. 실루엣 계수(0.1856)는 데이터가 구형으로 깔끔하게 밀집해 있지 않고 겹쳐 있음을 보여줍니다.

이유:

대다수를 노이즈(-1) 또는 단일 군집으로 처리: DBSCAN은 밀도가 높은 곳만 묶고 나머지는 노이즈로 처리합니다. 이 데이터셋 특성상 모든 데이터가 고르게 퍼져 있어 알고리즘이 거의 모든 데이터를 하나의 거대한 군집(0)으로 인식했습니다.

로지스틱 회귀와 유사한 현상: 결국 '전부 다 비구매(0)'라고 판단한 것과 같아져서 정확도는 96%로 높지만, 실제 구매자(1)를 전혀 찾지 못해 정밀도와 재현율이 0.0000이 됩니다. 반면 군집 간의 경계 형태 자체의 밀도 응집도를 나타내는 실루엣 계수는 0.2621로 상대적으로 높게 측정되었습니다.

4. 분포 기반: GMM (Gaussian Mixture Model)
지표: 정확도 0.6413 / 정밀도 0.0349 / 재현율 0.3103 / 실루엣 0.0196

이유:

확률적 소프트 클러스터링: GMM은 데이터가 확률적으로 어떤 분포에 속하는지 부드럽게(Soft) 나누어줍니다.

계층 기반 모델(Agglomerative Hierarchical Clustering)에 대한 설명과, 요청하신 대로 밀도 기반(DBSCAN) 모델을 제외하고 3가지 모델(중심 기반, 분포 기반, 계층 기반)로 재구성한 전체 대시보드 코드를 안내해 드립니다.

🌳 계층 기반 모델이란 무엇인가요?
계층적 군집화는 데이터들을 계층적인 트리(나무) 구조로 묶어 나가는 군집화 방식입니다.

작동 방식 (상향식 / Agglomerative):

처음에 데이터 하나하나를 각각의 독립된 개별 군집(총 N개)으로 시작합니다.

거리가 가장 가까운 두 군집을 서로 하나로 합칩니다.

이 과정을 반복하여 최종적으로 원하는 개수의 군집이 될 때까지 합쳐나갑니다.

특징: K-Means처럼 사전에 군집 개수를 무조건 강제하기보다, 데이터들이 어떤 순서로 합쳐지는지 덴드로그램(Dendrogram, 나무 구조 시각화)을 통해 전체적인 관계를 파악할 수 있다는 장점이 있습니다.

# 4. 시각화 영역: 산점도 및 교차 히트맵
# ---------------------------------------------------------
st.subheader("3. 📈 모델별 산점도(Scatter Plot) 및 사용자 동작 교차 히트맵(Cross Heatmap)")

tab_scatter, tab_heatmap = st.tabs(["산점도 시각화", "사용자 동작 교차 히트맵"])

df_sample['KM'] = labels_km.astype(str)
df_sample['GMM'] = labels_gmm.astype(str)
df_sample['AGG'] = labels_agg.astype(str)

# 1) 산점도 탭
with tab_scatter:
    st.markdown("#### 군집 모델별 참여도 vs 상호작용 산점도")
    selected_model_plot = st.selectbox(
        "산점도로 확인할 모델을 선택하세요:", 
        ["중심 기반 (K-Means)", "분포 기반 (GMM)", "계층 기반 (Agglomerative)"],
        key="scatter_select"
    )
    
    if selected_model_plot == "중심 기반 (K-Means)":
        fig_scat = px.scatter(df_sample, x='상호작용_수', y='참여도_스코어', color='KM', symbol='기기_유형', title=f"K-Means 군집 산점도 (실루엣: {sil_km:.4f})")
    elif selected_model_plot == "분포 기반 (GMM)":
        fig_scat = px.scatter(df_sample, x='상호작용_수', y='참여도_스코어', color='GMM', symbol='기기_유형', title=f"GMM 군집 산점도 (실루엣: {sil_gmm:.4f})")
    else:
        fig_scat = px.scatter(df_sample, x='상호작용_수', y='참여도_스코어', color='AGG', symbol='기기_유형', title=f"Agglomerative 군집 산점도 (실루엣: {sil_agg:.4f})")
        
    st.plotly_chart(fig_scat, use_container_width=True)

# 2) 교차 히트맵 탭
with tab_heatmap:
    st.markdown("#### 군집 모델별 그룹 × 사용자 동작 교차 히트맵")
    selected_model_heat = st.selectbox(
        "교차 히트맵으로 확인할 모델을 선택하세요:", 
        ["중심 기반 (K-Means)", "분포 기반 (GMM)", "계층 기반 (Agglomerative)"],
        key="heatmap_select"
    )
    
    map_col_dict = {
        "중심 기반 (K-Means)": 'KM',
        "분포 기반 (GMM)": 'GMM',
        "계층 기반 (Agglomerative)": 'AGG'
    }
    target_cluster_col = map_col_dict[selected_model_heat]
    
    heatmap_data = pd.crosstab(df_sample[target_cluster_col], df_sample['사용자_동작'])
    
    fig_heat = px.imshow(
        heatmap_data,
        text_auto=True,
        color_continuous_scale="Blues",
        title=f"[{selected_model_heat}] 군집 그룹별 사용자 동작 몰림 현상 (빈도수)",
        labels=dict(x="사용자 동작 (User Action)", y="군집 그룹 (Cluster)", color="세션 수")
    )
    st.plotly_chart(fig_heat, use_container_width=True)
    st.info("💡 **교차 히트맵 설명:** 각 군집 그룹 안에서 유저들이 **어떤 `사용자_동작`(조회, 장바구니, 클릭 등)에 가장 많이 몰려있는지** 빈도수를 색상 농도로 명확하게 파악할 수 있어 연구 목적에 완벽히 부합합니다.")
그럼 이 모델들은 체류시간이나 상호작용수 등이 이정도 수치이면 이 사람은 이 단계에 있을 것이다 라고 예측하는 모델인거야?

결론부터 말씀드리면, 엄밀히 말해 이 모델들은 사전에 정해진 단계를 직접 '예측'하는 모델이 아니라, 유사한 행동 패턴을 가진 사용자들을 끼리끼리 '그룹(군집)으로 묶어주는' 비지도 학습 모델입니다.

질문하신 내용이 정확히 어떤 의미인지, 지도학습(예측)과 비지도학습(군집화)의 차이를 통해 알기 쉽게 정리해 드릴게요.

🔍 예측(Prediction)과 군집화(Clustering)의 차이
만약 '예측' 모델이었다면 (지도학습):

"체류시간이 30초고 상호작용이 5회면 이 사람은 무조건 '장바구니' 단계일 거야"라고 정답을 미리 알려주고 학습시킨 뒤 맞추는 방식입니다. (예: 앞서 보았던 로지스틱 회귀 등)

지금 사용 중인 군집화 모델들은 (비지도 학습):

모델들은 정답을 모른 채, 오직 유저들의 체류시간, 상호작용 수, 참여도 스코어 등의 수치만 보고 "이전 데이터들을 보니 이 친구들은 서로 성향이 비슷하네?" 하며 자동으로 2개의 그룹(예: 그룹 0, 그룹 1)으로 쪼개기만 합니다.

💡 그럼 우리가 만든 대시보드는 어떻게 활용되는 건가요?
모델들이 스스로 유저들을 그룹 0과 그룹 1로 나눈 뒤, 앞서 만드신 '사용자 동작 교차 히트맵'을 통해 사후 분석을 수행합니다.

예시:

모델이 나눈 그룹 0의 사람들을 살펴보니, 대부분 view(조회) 단계에 체류시간이 짧게 몰려 있었습니다. ➔ "아, 그룹 0은 단순 구경만 하고 빨리 나가는 저참여 유저 군집이구나!"

모델이 나눈 그룹 1의 사람들을 살펴보니, add_to_cart(장바구니)나 click 단계에 상호작용이 많았습니다. ➔ "아, 그룹 1은 상품에 깊게 몰입해 장바구니까지 도달한 고참여 유저 군집이구나!"

즉, 모델이 직접 "이 단계일 것이다"라고 정답을 뱉어내는 것이 아니라, "이러한 참여도와 체류 패턴을 가진 유저들이 실제로 퍼넬의 어느 단계(사용자_동작)에 가장 많이 몰려있는지"를 우리가 시각적으로 발견할 수 있게 도와주는 도구입니다!
